data fm turns a dataset into sound.

add a dataset by loading a csv file or pasting cells from a spreadsheet. assign a column an instrument and a parameter for the data to change. add new layers for more columns or more datasets. press play to hear the dataset stretched across the length of the piece.

export midi saves every layer as its own track in one midi file, with brightness as cc74 and volume as cc11.

built with tone.js.
